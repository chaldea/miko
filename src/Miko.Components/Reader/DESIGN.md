# 阅读器设计

对应 `issues/feat-components-reader.md`。`BookReader` 和 `ComicReader` 保持独立参数与交互，共用目录、按需加载、导航、缓存、状态提示和生命周期。

## 分层

- `IReaderSource`：`GetDocumentAsync` 只取有序目录，`ReadAsync(entry)` 只取指定章节或图片。目录项使用稳定 ID；页码是零基索引。`DelegateReaderSource` 可以分别对接远程目录与正文 API，不要求整文件下载或统一 URL 规则。
- `ReaderController`：源切换、加载／错误／空状态、重试、单双页导航、取消和请求版本检查。取消后的提供器即使返回旧结果也不能覆盖当前结果。缓存按最近使用淘汰，默认最多 6 项且不超过 32 MiB；超大项显示但不缓存，当前内容另计。不自动预取，双页只请求当前两页。
- `FileReaderSource`：文件解析运行在线程池，以信号量串行访问压缩包和 PDF。元数据不解析所有 EPUB 章节或解码所有漫画图片。每次只解压当前条目，不向磁盘解压文件。默认限制单条目 64 MiB、目录 100,000 项、PDF 栅格 16,000,000 像素。
- `ReaderComponentBase`：原生元素工具栏、目录、外观／设置面板、状态层、键盘和手势。`ReaderComponentBase.Chrome.cs` 负责覆盖层布局，`ReaderControls` 提供图标和带预览／提交区分的触控滑条。目录面板每次显示 50 项。后台通知通过引擎 Dispatcher 应用到 UI，移除后不再更新。组件只释放自己的控制器、图标和已解码图像；源由应用负责释放。
- `BookLayout` / `BookView`：使用引擎 `TextWrapper` 和 `IGraphicsFactory.CreateText` 测量、换行、整形；按完整行分页，不截断行。改变字号或视口时根据文本偏移定位到新页。滚动与分页共享行布局。目录索引表示章节，`PageIndex` / `PageCount` 表示当前章节的可视分页。
- `ReaderImageView`：只解码当前图片／双页，页面离开后释放。双页按阅读顺序排列，横向或纵向布局；适应宽度时从图片顶部开始，超出部分可拖动／滚轮平移。双击或双点切换缩放，放大后可拖动查看。

## 手机 UI 与交互

参考 `issues/components-reader` 的手机布局，默认 `Immersive=true`：正文上方显示章节，下方显示页码；单击显示顶部返回栏和底部进度／工具栏。工具栏和底部面板均为覆盖层，不参与正文高度计算，因此开关面板不会重新分页。设置面板最大宽度 560，最大高度扣除安全区和底部工具栏；矮屏下内容独立滚动。常用按钮／滑条触控高度不低于 44，横竖屏均考虑安全区。

目录、外观、设置三个面板互斥。完成按钮、遮罩、系统返回均可关闭面板；系统返回按“关闭面板 → 隐藏工具栏 → `BackRequested`”顺序处理。组件以 Overlay 优先级注册返回处理，销毁时注销。`ShowToolbar` 控制点击显隐的可用性；`Immersive=false` 可让工具栏初始显示，应用也可显式调用面板／控制栏方法。

单击等待 350 ms 后切换工具栏，为双击图片缩放留出识别窗口；拖动、双击、关闭或销毁会取消待处理的单击。定时回调经引擎 Dispatcher 并检查版本，避免过期回调改变页面。进度滑条拖动时仅预览，松手才请求章节／页面。文本进度按章节等分估算（不为统计长度预加载全书），切换章节后等待文字排版再定位到对应页；100% 定位末章末页。

外观面板提供明亮、纸张、护眼、夜间底色与 `Dimness`。后者仅在正文绘制遮光层，不调用设备亮度接口。字体、字号、间距、页边距、翻页／滚动和漫画相关配置均保留组件参数，也可通过默认设置面板调整。

## 格式与依赖

| 格式 | 处理方式 |
| --- | --- |
| TXT | BOM 检测，默认 UTF-8，可指定编码；按换行／字素边界分段，默认每段约 16,000 字符 |
| EPUB | ZIP + XML；解析 container → OPF manifest/spine，支持 EPUB 3 nav 与 EPUB 2 NCX 标签，按 spine 顺序加载章节；AngleSharp 解析正文和 HTML 导航，支持命名实体，不执行脚本或加载外部资源 |
| PDF | PdfPig + PdfPig.Rendering.Skia，默认将单页渲染为 PNG（包括扫描页）；`ReflowPdf` 提取正文并重排 |
| CBZ | BCL ZipArchive；筛选图片，忽略隐藏条目和 __MACOSX，按数字自然排序 |
| CBR | SharpCompress 读取 RAR；与 CBZ 使用同一图片顺序和显示逻辑 |

PDF 的后端依赖只出现在文件适配器中，UI 的绘制仍通过 `Miko.Graphics`。PdfPig / PdfPig.Rendering.Skia 使用 Apache-2.0；SharpCompress 和 AngleSharp 使用 MIT。PDF 渲染依赖该包的图像过滤器和 Skia 后端，不能视为纯托管解析路径。

EPUB 当前提供正文重排，不重现出版物 CSS、内嵌图片和固定版式；XML 外部资源解析禁用，脚本／样式内容不显示。PDF 原版页面不能应用字体／行距设置，需显式启用 `ReflowPdf`；扫描件重排不含 OCR，可能没有文本。加密／DRM 书籍和密码压缩包不支持。滚动模式在当前章节中滚动，跨章节使用目录或翻页按钮。

## 所有权与取消

提供器返回的目录会复制为只读快照，内容及其图像缓冲必须保持不可变。提供器应支持取消及重叠请求；控制器不假定取消会立即结束网络请求。调用方可以复用同一个源，组件不会擅自释放它。停止使用文件源后应 `await source.DisposeAsync()`；释放会等待正在进行的解析，随后关闭句柄。解析器内部同步工作不能被立即打断，但操作前后和流读取中均检查取消，旧结果不会进入 UI。

## 验证

`tests/Miko.Components.Tests/Reader` 覆盖目录／页面分别加载、缓存淘汰、奇数页双页边界、错误重试、取消和晚到结果、TXT 编码与字素、EPUB spine／导航／相对路径、CBZ／CBR 自然排序、PDF 文本与扫描页，以及真实引擎的分页、重排、滚动、像素顺序、焦点、双击、滑动和错误显示。

UI 回归覆盖单击／双击互斥、待执行手势销毁、面板不改变分页、遮罩与返回层级、手机横竖屏安全区、进度拖动不重复请求与末页定位。

`examples/Components/MikoApp.Reader` 提供共享书架页面、电子书／漫画筛选、四本内存示例，以及按类型进入对应阅读器的导航。退出阅读器时将设置和目录索引保留在书架模型内，仅在本次应用会话有效；不保存章节内分页。Desktop、Android、iOS 启动项目复用该页面。桌面可传入本地文件加入书架，`--verify <目录>` 通过真实引擎和触控命中验证书架往返、设置应用、安全区夜间底色，并输出手机与桌面截图。

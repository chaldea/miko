# Component Libraries

Miko ships ready-made Razor component libraries on top of the built-in [elements](../guide/elements.md). Reference the package, register it on the app builder, and use its components like any other Razor component.

| Library | Status | Reference |
| --- | --- | --- |
| `Miko.Ionic` | Port of the Ionic Framework components, with Material Design and iOS modes. Used by every app template. | [Ionic components](./ionic/index.md) |
| `Miko.Bootstrap` | Bootstrap-inspired components. Preview — the API is still changing. | [Bootstrap example gallery](../examples.md#bootstrap) and the [source](https://github.com/chaldea/miko/tree/main/src/Miko.Bootstrap/Components) |

To build your own components, see [Razor Components](../guide/razor-components.md).
